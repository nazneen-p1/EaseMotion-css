# Ease Black Hole Loader

## Overview

Ease Black Hole Loader is a futuristic loading animation inspired by space physics. Colorful particles spiral toward a glowing black hole and continuously regenerate, creating a smooth infinite loading effect.

---

## Features

- 🌌 Black hole inspired animation
- ✨ Spiraling particles
- 🎨 Multiple glowing particle colors
- 🔄 Infinite loading loop
- ⚡ Pure HTML & CSS
- 📱 Responsive layout

---

## Demo

Includes:

- Central black hole
- Six animated particles
- Continuous spiral animation
- Loading text

---

## Usage

```html
<div class="loader">
    <div class="black-hole"></div>
</div>
```

---

## Customization

You can customize:

- Hole size
- Particle colors
- Rotation speed
- Number of particles
- Glow intensity

---

## Browser Support

Compatible with all modern browsers supporting CSS transforms and animations.
